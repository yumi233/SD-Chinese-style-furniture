# 使用说明

## 1. 配置生成模型

点击页面顶部的 `连接本地模型`，可以配置：

- 默认引擎
- Stable Diffusion WebUI 地址
- LoRA 模型选择
- ComfyUI 地址
- ComfyUI checkpoint
- ComfyUI workflow 文件路径
- 文字大模型增强开关与 OpenAI 兼容接口
- 图像大模型的 OpenAI 兼容接口

默认生成模式可以选择本地模型、图像大模型，或二者并行。并行结果会分别标注 `Stable Diffusion WebUI`、`ComfyUI` 或 `图像大模型`。

保存后，网页生成会直接使用新的后端配置，并写入 `MODEL_CONFIG_FILE` 指向的服务端 JSON 文件；配置页面只对管理员开放，API Key 只在服务端保存，读取时仅返回是否已配置。

## 账号和权限

注册或登录后才能生成、运行智能体、读取或删除历史、读取历史图片和导出报告。历史记录按当前用户隔离。先注册并登录，再通过 `GET /api/v1/auth/me` 取得随机 `user.id`；把该 ID 写入部署环境的 `MUSHENG_ADMIN_USER_IDS` 并重启，才能进入模型配置管理。注册提交的 `role` 或 `id` 不会授予管理员权限。Compose 服务可以使用 `make admin-id EMAIL=you@example.com` 从容器用户文件只读查询 ID。

## 2. 输入提示词

推荐两种用法：

### 方式 A：中文自然语言

例如：

```text
一张明式圈椅放在素雅茶室中，黑胡桃木，榫卯结构，晨光斜照，留白克制，高级产品摄影
```

系统会自动：

- 识别中文
- 翻译英文关键词
- 做中式家具场景增强

### 方式 B：结构化英文 Prompt

如果你已经有成熟的 SD Prompt，直接粘贴即可。

系统会尽量原样保留，不会过度强化。

## 3. 查看三段式提示词

在 `AI 优化提示词` 面板里可以看到：

- 中文原始输入
- 自动翻译英文 Prompt
- 强化后 Prompt

这是排查“翻译有问题”还是“增强有问题”的核心区域。

## 4. 选择基础参数

目前前端保留了几个高频控制项：

- 风格预设
- 精细度
- 画布尺寸：16:9 720p、16:9 1080p、4:3 720p、4:3 1080p
- 空间氛围

默认更偏“稳出图”而不是“高参数拉满”。

## 5. 生成后操作

每张结果卡片支持：

- 放大
- 下载
- 再来一版

“再来一版”支持：

- 同参数重跑
- 换个角度
- 更强光影
- 更克制陈设

## 6. 设计方案：确认需求、选方向、继续细化

生成前，「约束」面板列出系统锁定的需求：必须满足的、禁止出现的（包括由“无扶手”“全金属”推出的）、可以自由发挥的部分和系统做的假设。需求里有核心矛盾（例如“无扶手的圈椅”）时，会先请你选择，再生成。

- 「参考」面板：上传自己的参考图或文档（PNG / JPEG / WebP ≤ 5 MB，txt / md ≤ 200 KB，PDF ≤ 6 MB），勾选本次使用，并标明用途：轮廓、材质、结构或氛围。只有你的账号能看到。
- 「方向」面板：没有想法时，给出三个明显不同的方向，默认第一个最贴合需求。
- 「案例」面板：附出处的当代案例，每条材料和尺寸都标明依据（出处写明 / 图片可见 / 推断 / 未知）。

生成后，结果面板显示锁定的需求、用到的参考及用途、这一版改了什么、还没解决的问题，以及版本列表（可勾选两版对比，或恢复早先版本）。下面有四个操作：

- **生成另一个版本**：方向不变，只换一个受控变量。
- **探索新方向**：换一个设计方向。
- **继续细化**：写下要改的地方（例如“保留这把椅子，背板更薄，坐垫换成亚麻”），上一版图片作为输入，其他部分保持不变。新要求对它提到的部分覆盖旧要求。
- **三视图**：正视、侧视、俯视三张概念示意图，不是工程图纸。

评审结果是模型的判断，不认证木材种类、承重或结构安全。

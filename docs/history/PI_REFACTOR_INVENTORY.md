## 1. 项目和现有工作流

仓库：`yumi233/SD-Chinese-style-furniture`。产品名称为木生·AI，定位是围绕中式家具比例、材料、风格和空间意境的图片生成工作台。

当前主线：描述家具 → 选择风格与画布 → 创建生成任务 → 可选多轮视觉评审 → 查看结果、下载与再次迭代 → 保存和恢复历史。首页为 `/`，工作台为 `/studio`。

| 领域 | 源码中已有内容 | 重构时应保留的行为 |
| --- | --- | --- |
| 页面 | 原生 HTML/CSS/JS 首页、制图台、设置、历史与评审区域 | 中文界面、画布操作、空态与失败提示、登录引导和移动布局 |
| 需求 | 中文描述、英文提示词、风格、材料氛围、尺寸和质量设置 | 请求归一化、可选文字模型增强与失败回退 |
| 生成 | Codex CLI、在线图像模型，以及后端保留的 A1111/ComfyUI 适配 | 实际可用引擎、图片验证、下载与历史持久化 |
| 智能体 | 生图、评分、修正、再次生成，最多三轮 | 最佳轮、逐轮结果、目标分数、停止后保留已完成图片 |
| 任务 | 异步任务、轮询、页面刷新恢复活动任务、请求去重 | 账号归属、全局单活动任务、失败脱敏、避免重复计费 |
| 账号 | 注册、登录、HttpOnly session、资料头像、管理员配置 | 用户数据隔离，普通账号不能改实例模型配置 |
| 资料 | 内置教学案例、品牌和风格图片 | 明确图片用途与来源，案例不冒充实时外部知识库 |
| 发布 | Node/Express、Docker、Compose、GitHub Actions/GHCR | 保持可回退部署，迁移与镜像说明同步更新 |

当前唯一直接运行依赖是 Express；后端为 CommonJS。任务状态、用户、模型配置与历史使用文件存储，不应按已具备多实例数据库来设计迁移。

## 3. 已发现的文档差异与能力缺口

- 旧架构文档写“长任务只能一次 HTTP 等待”，当前已有 `/generation-tasks` 创建、查询与停止接口；刷新恢复和服务端重启恢复是不同能力。重启后的活动任务被结算为完成或失败，不自动续跑。
- 旧文档把在线图片模型当作唯一界面引擎，当前界面还包含 Codex 图像生成，是否可用由部署配置决定。
- 旧前端交接文档提到报告功能，当前路由和工作台没有完整报告导出链路。`REFACTOR_HANDOFF.md` 保留为历史记录，当前事实以源码及已更新的 `PROJECT_OVERVIEW.md` 为准。
- Provider 内部有参考图片参数，不等于产品已经具备设计参考图上传与管理流程。
- 当前没有完整的项目管理、设计会话管理、CAD/三维建模或结构承重验证能力。视觉模型评分是建议，不能当作工程验证。
- 当前后台任务是单进程文件持久化机制，没有跨进程可靠队列、模型费用核算或多实例调度。

## 4. Pi 作为智能体内核的建议边界

保留浏览器界面、Express API、身份认证、任务和历史外壳，在服务器中新增 Pi 适配层，让 Pi 负责需求澄清、工具选择和迭代编排。图片生成和视觉评审仍通过已有 Provider 执行，Pi 不被当作图像生成引擎本身。

建议工具包括：读取用户已授权的设计上下文、检索内置案例、生成图片、评审图片、保存当前设计版本。每个工具都由服务端绑定账号与任务，校验参数及输出，只返回本次工作必要的信息。面向网页用户的 Pi 会话不默认开放任意 shell、任意文件读写或服务端密钥。

新会话必须明确关联账号；是否增加“项目”实体应在产品需求阶段决定。现有生成历史可以关联未来会话，但不能未经转换就视为完整 Pi 会话记录。任务停止需区分停止后续工具调用与取消已经提交的外部生成请求；后者取决于 Provider 的真实支持。

| 阶段 | 工作 | 验收标准 |
| --- | --- | --- |
| 0：内容基线 | 本次盘点、更新架构事实、列出私有资料缺口 | 文档与当前路由一致，公开代码和私有数据边界清楚 |
| 1：最小内核 | 核实 Pi 当前 SDK 与运行环境，增加可配置的服务端适配层 | 用本地 mock 工具跑通一次对话与工具事件；旧流程仍可运行 |
| 2：生成闭环 | 将生成、评审、案例检索接为受限工具 | 任务状态、图片结果、轮次与历史一致；失败不会重复提交生成 |
| 3：会话恢复 | 增加设计会话、版本关系与事件展示 | 刷新、重新登录、重启后的恢复语义明确；账号之间不可串读 |
| 4：联调交付 | 经明确授权后做真实模型联调，更新容器及发布材料 | 核对真实图片、费用、停止行为、浏览器流程与数据备份回退 |

本轮只执行阶段 0，不安装 Pi、不调用外部模型、不修改线上服务、不推送或部署。

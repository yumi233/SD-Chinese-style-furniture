# 灵感册动效验收

2026-10-30。用户已认可基础组件，本轮只新增空间动效组件并应用到主页展示区域。画布业务功能不在本轮范围。

## 来源与观察

参考 [Puploop：用 ai 把想法落地，做一个作品集首页分享](https://xhslink.cn/o/A5XPxpNS1aQ)。通过已登录浏览器实际播放，保存该笔记公开返回的视频供本地分析；ffprobe 确认 1920×1080、23.5 秒。查看了全段关键帧和展开片段帧序列。没有复用视频中的作品图、贴纸、文字或人物形象。

重点借鉴：文件夹收纳时保留卡片预告；悬停将卡片按不同角度与间距展开；单卡悬停向前抬起；前盖随展开倾斜；底部投影随高度改变；离开后返回收纳态。本站继续使用原有家具 SVG、浅蓝玻璃与磨砂亚克力。

## 实现

- `public/ui/idea-folder.css`：独立材质与空间过渡，未改基础按钮、输入、弹层组件样式。
- `public/js/modules/idea-folder.js`：同一个组件用于主页和组件库，状态区分悬停、点击固定展开、键盘焦点和 Esc 收起。
- 主页右侧原示意展示替换为可展开的灵感册；下方风格列表、主页版式、工作台布局保留。
- 展开卡片点击进入 `/studio?style=...`，对应明式、当代、宋韵、禅意四个已有风格。

本版调校参数（并非对视频的精密测量）：展开 700ms、各卡错开 35ms；收回 560ms、反向错开 20ms；离开容差 100ms；单卡前移 320ms；指针倾斜控制在约 ±2.5° / ±3.5°。使用可中断的 CSS transition，不排队播放，不做持续循环动画。

## 操作

- 桌面：移入展开，移开收回；卡片悬停前移，点击进入工作台。
- 键盘：聚焦文件夹后 Enter/Space 展开，Tab 访问设计卡片，Esc 收起并返回触发按钮。
- 手机：点击文件夹展开，再次点击收起；卡片可直接点击。点击外部也会收起。
- 收起时卡片 inert 且 aria-hidden，防止隐藏目标参与键盘导航。
- 遵守减少动态效果与减少透明度；减少动态效果时取消错峰和倾斜，保留状态变化。

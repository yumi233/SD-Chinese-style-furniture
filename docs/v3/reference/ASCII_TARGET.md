# 用户认可的 ASCII 目标效果（「纸面」样式）

用户明确认可 `ascii-target.png`。正式模块需要新增一种样式 `look: "paper"`，并在首页、登录页的大面板中**默认使用**：

- **不画底图**，背景就是纸色 #F5F7EF（夜间用 --paper）。
- 字符序列与色调计算沿用 003 规格（取样暗部；raw 占 0.14、norm 占 0.86，减 0.22 后除以 0.70，再做 smoothstep）。
- **字符颜色**：按该格的亮度 L 到 meadow 色板中取色（色阶 0 / 0.4 / 0.74 / 1 → #2B361F / #677D45 / #AEBA78 / #E5E1BD），**不透明**，不做 HSV 提亮。
- 格子：桌面字号 12px（Menlo / ui-monospace），格宽约 8px；面板宽度小于 480 时字号 9px。
- 顶部 36% 的高度内，字符和背景按 `fade = (1 − y/0.36)^1.4` 渐隐到白色。
- 底图：`public/assets/hero-meadow.png`（3:2）。左下约三分之一用来压标题。
- 已知问题：左下地面会出现横向字符带。压标题的区域可以局部再淡化一层。

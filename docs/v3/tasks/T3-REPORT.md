- 三个生成入口支持可选 `parentId`，验证类型、长度及当前用户所有权；管理员也不能引用其他用户的记录。
- 普通生成和智能体历史保存父版本；旧记录读取时返回 `null`。删除父记录、生成过程中父记录被删除或历史容量淘汰父记录时，子记录保留并解除关联。

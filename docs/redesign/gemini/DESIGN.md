## 1. 设计理念与核心主张

### 1.1 一句话设计理念
> **“以计算解构宋明，以逻辑生长器物。”**

### 1.2 为什么它是年轻化、超前化的？
1. **脱离“仿古做旧”的陈旧陷阱**：  
   传统中式家具软件习惯堆砌仿古花纹、古画背景或老式后台表格，显得沉重陈腐。新一代年轻独立设计师与先锋工作室，关注的是中式家具深层的**骨相律动、榫卯力学平衡、月牙弧率张力与虚实留白**。构形场将这些法度转化为参数化几何变量，以高精度数码工作台（CAD / Studio）的形式呈现。
2. **数码物态化实验室美学 (Digital Materialization)**：  
   家具不再是僵硬死板的实体照片，而是能够被计算、切片、重组的数字器物。通过 **4×4 Bayer 抖动矩阵 (Dither)** 与 **ASCII 字符密度着色器**，家具在屏幕上呈现出由网格、像素、扫描线交织的未来物质感，锋利、通透且极具视觉张力。
3. **透明可控的智能体生产力**：  
   拒绝“盲盒转圈生图”。设计过程被重塑为四个透明阶段（意图解构 → 骨相推演 → 材质光影 → 六维评审），并提供图纸级的“框选改一处”与“无级滑动拉幕对比”，将一次性生成转变为严谨可追溯的设计推演。

## 3. 关键业务流程详述

### 3.1 首次进入 → 第一次生成
1. **首次进入**：用户访问官网 `index.html`，无需注册即可在首屏的「实时构形操场」直接点击切换家具原型（圈椅、条案、罗汉榻、博古架），滑动调节 Bayer Dither 像素颗粒与遮罩，感受数码解构的魅力。
2. **设定带入**：点击「将此设定带入工作台」，浏览器通过 `sessionStorage` 将当前器物类型、意境风格与着色器模式直接传递到 `studio.html`。
3. **输入与增强**：在工作台左侧输入简明中式概念（如“当代宋韵极简圈椅，五接月牙扶手，轻悬舒展，深棕黑胡桃”），系统实时呈现自动翻译和结构化增强的英文提示词预览。
4. **触发推演**：点击「执行构形推演」，进入透明的 4 阶段推进。

### 3.2 生成过程与评审打分
1. **生成的感觉**：
   - 绝非普通转圈，右侧状态栏清晰展示真实的推演心智：
     - **阶段 1：意向解构与榫卯受力分析 (0% - 25%)**
     - **阶段 2：骨相起稿与形态演化 (25% - 55%)**
     - **阶段 3：材质纹理与环境光影烘焙 (55% - 80%)**
     - **阶段 4：视觉多维专家模型评审 (80% - 100%)**
   - 伴随高精度毫秒计时器（如 `1.8s`, `3.2s`），右上角提供显目的「■ 终止推演」按钮。用户若中途取消，系统明确反馈：“任务已安全中止，设计配额毫发无损”。
2. **专家模型评审**：
   - 任务完成后，右侧雷达条呈现文化准确性 (92)、结构合理性 (90)、材料工艺 (86)、设计创新 (91)、场景适配 (88)、AI 使用 (87) 六项量化得分；
   - 专家模型提供结构级短评（如：“月牙扶手弧度圆融，但鹅脖交界处可更纤薄收束”）。

### 3.3 修改与“框选改一处” (Inpainting)
1. **全局修改**：用户可在评审建议卡片直接点击「采纳此建议并自动迭代」，智能体自动生成 V2。
2. **框选改一处**：
   - 在画布工具栏点击「⛶ 框选局部改动」工具；
   - 在画布圈椅扶手处拖拽出一个琥珀色虚线框；
   - 框选结束后，弹出贴紧框选区域的气泡浮层，自动识别区域为“圈椅月牙扶手与立柱交接处”，默认填入建议“扶手减薄 40%，端头收窄，保留黑胡桃微晶质感”；
   - 点击「生成新版本」，系统锁定其余所有部件（椅腿、椅盘、券口牙子），只针对扶手进行收薄重算，生成全新分支版本 **V3 (局部框改: 扶手纤薄收窄)**。

### 3.4 版本比较 (Diff Compare)
1. 在画布浮动工具栏点击「⇔ 版本对比」；
2. 画布立即进入左右分屏拉幕模式：左半区为 V1（初稿饱满款），右半区为当前选中的 V3（纤薄收窄款）；
3. 用户按住中央发光青色手柄左右滑动，两版的弧线转折、鹅脖收束与木料厚度差异在同一视口下毫厘毕现。

### 3.5 规格展卡导出 (Export)
1. 点击顶部「⤓ 导出规格展卡」；
2. 弹出高品质建筑图纸级 A4 / 16:9 作品展卡：
   - 左侧为当前选定着色器模式（支持原画或 Dither 数码切片）的高清渲染图；
   - 标明 4×4 Bayer 矩阵采样指纹、分辨率与比例；
   - 右侧排列标准化工程参数（主材：微晶深棕黑胡桃、软包：高密灰织锦、外形尺寸：640×610×910mm）；
   - 六维专家评审条带与认证哈希码；
   - 点击「下载高清展卡」，浏览器自动保存为 PNG 图片。

### 3.6 回到历史作品与会话恢复
- 页面支持重命名项目、读取预设及断线后自本地会话自动恢复（Hydration）；
- 版本树记录 V1、V2、V3...，点击任意版本卡片即可瞬间切换画布呈现与评审档案。

## 5. 视觉系统与 Token 嵌套体系

### 5.1 递进式圆角 Token 体系 (严格遵循 r = R - p)
本系统彻底贯彻内外共圆心几何准则，所有内边距 $p$、间距 $gap$、外圆角 $R$、内圆角 $r$ 均严格对齐在 **4px 网格** 上：

| 层级 | Token 名称 | 尺寸 | 使用场景 | 嵌套关系推导 |
| :--- | :--- | :--- | :--- | :--- |
| **层级 1** | `--radius-window` | `32px` | 导出展卡大模态、工作台全屏视窗外框 | 外层最高容器 ($R = 32px$) |
| **层级 2** | `--radius-card` | `24px` | 首页操场卡片、状态弹窗、移动端抽屉底托 | $R = 24px$，内边距 $p = 12px$ |
| **层级 3** | `--radius-panel` | `16px` | 操场控制列、画布内悬浮工具条外壳、展卡渲染画框 | $r = 32 - 16 = 16px$ 或 $r = 24 - 8 = 16px$ |
| **层级 4** | `--radius-sub` | `12px` | 工作台侧栏卡片、框选气泡浮层、评审条内胆 | $r = 24 - 12 = 12px$ |
| **层级 5** | `--radius-control` | `8px` | 文本输入域、主要按钮、分段选择器子项 | $r = 16 - 8 = 8px$ 或 $r = 12 - 4 = 8px$ |
| **层级 6** | `--radius-tag` | `4px` | 状态指示点、微型参数标签、进度条滑轨槽 | $r = 8 - 4 = 4px$ (系统最小圆角) |
| **全圆** | `--radius-pill` | `9999px` | 首页徽章、对比滑块手柄、纯圆控制点 | 保持无极全圆 |

### 5.2 连续曲率（超椭圆）渐进增强
在现代高版本浏览器（Chrome / Edge 139+）上启用超椭圆平滑曲率，其他浏览器平稳回退至经典圆角：
```css
@supports (corner-shape: superellipse(1.25)) {
  :where(*) {
    corner-shape: superellipse(1.25);
  }
}
:where(.pill, .round) {
  corner-shape: round;
}
```

### 5.3 色彩与对比度 (WCAG AA 达标)
- **画布深黑底色**：`#090A0D`（吸收环境光，聚焦器物形体）
- **工作台基面色**：`#15181E` / 浮层强化色 `#1C212A`
- **边框阶梯**：微弱 `rgba(255,255,255,0.08)` / 中度 `0.16` / 强交互聚焦 `0.28`
- **文本层级**：主文本 `#F3F4F6` (对比度 > 13:1) / 次级文本 `#9CA3AF` / 标注文本 `#6B7280`
- **数码功能色**：
  - 极光数码青 (`#00F5D4`)：代表 CAD 高精标线、当前选中版本、算法最佳分；
  - 智能体运算蓝 (`#3B82F6`)：代表推演进程与英文提示词增强；
  - 局部框选琥珀金 (`#F59E0B`)：代表人工干预框选、重点评审建议；
  - 安全翠绿 (`#10B981`)：代表榫卯荷载校验通过；
  - 警示红 (`#EF4444`)：代表任务终止或异常。

### 5.4 字体与排版
- 正文：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", sans-serif`
- 参数、坐标、评分、计时器：`"SF Mono", "Fira Code", "JetBrains Mono", Consolas, monospace`
- **排版自明原则**：剔除所有无意义的装饰性英文小标题，只保留结构本身。

### 5.5 动效物理原则与时长
- **时长**：
  - 微交互（Hover、Tab 切换）：`150ms` (`--duration-fast`)
  - 状态转场、浮层展开：`250ms` (`--duration-normal`)
  - 画布自适应平移复位：`400ms` (`--duration-slow`)
- **缓动曲线**：`cubic-bezier(0.16, 1, 0.3, 1)`（迅捷响应、柔和刹车，具备机械阻尼感）。
- **无障碍保障**：严格监听 `@media (prefers-reduced-motion: reduce)`，在用户开启减弱动态效果时将动画与过渡时间强制降为 `0.01ms`。

## 6. 两条指定设计方案的具体落地

### 6.1 方案 5.1：递进式圆角 + 连续曲率圆角
- **具体使用位置**：
  - 主视窗到侧栏卡片：视窗外壳 32px → 侧栏内边距 12px → 卡片容器 12px；
  - 卡片容器到控件：卡片 12px → 内边距 8px → 输入框/按钮 8px；
  - 控件到内嵌徽章：按钮 8px → 内边距 4px → 状态小标 4px；
  - 悬浮在画布上的 CAD 工具栏：容器圆角 12px，内边距 4px，内部工具按钮 8px；
  - 彻底规避了传统界面中“内层比外层更圆”或“尖角顶着圆角”的几何违和感。

### 6.2 方案 5.2：ASCII 与 Dither 参数化数字物态效果
- **设计初衷彻底落地**：
  将中式家具从“老式实物照”彻底解构为“数码切片”，在手机与桌面都清晰可辨。
- **Dither 模式数学实现**：
  - 构建标准化 $4 \times 4$ Bayer 阈值矩阵：
    $$\begin{bmatrix} 0/16 & 8/16 & 2/16 & 10/16 \\ 12/16 & 4/16 & 14/16 & 6/16 \\ 3/16 & 11/16 & 1/16 & 9/16 \\ 15/16 & 7/16 & 13/16 & 5/16 \end{bmatrix}$$
  - 将离线画布降采样至像素块网格（滑块支持 $2px \sim 10px$ 调节）；
  - 提取感知明度 $Lum = 0.299R + 0.587G + 0.114B$，叠加明暗对比度与 Bayer 阈值，量化到 4 级色阶；
  - 叠加纵向扫描遮罩（推荐值 88%），产生如精密光栅切片般的数码物态感。
- **ASCII 模式实现**：
  - 将画面划分至 $8px \sim 16px$ 等宽字符网格；
  - 字符集根据灰度密度映射：` .:-=+*#%@`；
  - 叠加推荐值 90% 的纵向字符扫描遮罩，手机 Retina 屏幕上依然颗粒分明。
- **可交互调节**：
  - 工作台工具栏常驻「⚙ 滤镜参数」，用户可随时呼出浮动微调面板，拖动滑块实时查看家具像素矩阵的密度重构。

| **1. 空态 (Empty)** | 首次进入工作台或清空设计项目 | 画布呈现深暗网格与提示“等待输入构想描述并触发推演”；右侧任务栏显示“等待任务/空闲”；提示词区提供 4 个一键预设灵感胶囊 | 尚未产生版本消耗 | 点击提示词预设或输入后点击“执行构形推演” |
| **2. 生成中 (Generating)** | 点击生成、框选局部改动或采纳建议 | 右侧 4 阶段进度条动态延伸，对应步骤高亮并附带毫秒计时器；右上角浮现红色「■ 终止推演」按钮；画布保持微弱待命脉冲 | 后台智能体计算中 | 随时可点击「终止推演」中止当前计算 |
| **3. 部分结果 (Partial)** | 多轮推演中第 1 轮完成、第 2 轮评审尚未出炉 | 画布呈现先行阶段的骨相结构线稿（Blueprint）；右侧步骤 1、2 完成，步骤 3、4 待定；进度条停留在 60% | 中间临时数据，可抢先预览 | 等待最终评审，或直接基于当前骨相框选微调 |
| **4. 成功 (Success)** | 智能体自修推演完毕且达到目标基准分 (≥85) | 画布高品质呈现最终渲染图或 Dither 点阵；右侧 4 步骤全绿亮起；六维雷达打分展开，版本树新增对应版本节点；状态标为“推演成功 · 已锁定” | 正常记录于会话与版本树 | 支持框选改动、双版对比、切换着色器或导出展卡 |

| **6. 已停止 (Stopped)** | 用户在生成中途点击了「终止推演」 | 弹出琥珀色提示框：“推演已在第 2 阶段安全中止。当前中间草图已自动暂存，设计配额毫发无损”；右侧计时器锁定停顿 | 安全中断，不扣减点数 | 点击「继续未完任务」接续推演，或调整参数重跑 |
| **7. 断线 (Offline)** | 用户网络离线、脱机使用 | 弹出网络脱机保护提示：“当前处于脱机环境。所有本地 Canvas 引擎与 Bayer / ASCII 滤镜均可完全正常运行” | 本地数据自动缓存在 Session | 离线继续调节本地滤镜与对比，重连后自动同步 |
| **8. 刷新恢复 (Hydrated)** | 浏览器意外刷新或重新打开页面 | 状态栏提示“会话已刷新恢复 (恢复于 10秒前)”；完整恢复上一轮评审结果、锁定的材质记忆、提示词输入与多版本演化树 | 会话无缝衔接 | 无缝继续设计，无任何上下文丢失感 |

## 9. 方案自检报告 (Self-Audit)

### 9.1 我们已经验证过的
1. **纯离线运行与零外部依赖**：  
   在禁用外部 CDN、离线环境下对全部 HTML、CSS、JS 进行静态加载验证，所有家具图形均由 `furniture-engine.js` 纯原生 Canvas 2D 算法实时绘制，不引用任何网络资源或现有仓库图片。
2. **语法与代码质量**：  
   所有新建 JS 文件经 `node --check` 逐一校验，无语法错误、无变量泄漏。
3. **指定方案 5.1 递进式圆角嵌套**：  
   严格复核 CSS 代码中每一个 Dialog（32px）、Card（24px）、Panel（16px）、Sub-panel（12px）、Control（8px）、Tag（4px）的数值，完全满足 $r = R - p$ 几何一致性；且加入了 `@supports (corner-shape: superellipse(1.25))` 超椭圆渐进增强。
4. **指定方案 5.2 ASCII 与 Dither 效果**：  
   - Bayer 4×4 阈值算法与色阶量化运转正常，切片与纵向遮罩（88% 与 90%）在 1440 桌面与 390 手机上均具极高辨识度与数码张力；
   - 提供了滑块实时调参并能无级切换原画、Dither、ASCII、蓝图模式。
5. **工作台关键交互链路**：  
   - “输入概念 → 点击生成 → 4 阶段推进并可终止 → 六维雷达打分 → 采纳建议生成 V2 → 画布拉框框选改一处生成 V3 → 双版本左右窗帘拉幕对比 → 导出规格展卡下载 PNG”链路全闭环可运行。
6. **响应式断点测试**：  
   在桌面宽屏 1440px 与移动端竖屏 390px 视口下分别验证，移动端底部五 Tab 栏与抽屉工作流自然顺畅，无横向溢出。
7. **八类状态可测试性**：  
   工作台底部设计了 Benchmark 状态切换快捷栏，任何人点击即可直观检验空态、生成中、部分结果、成功、失败（不扣次数）、已停止、断线、刷新恢复的全部视图与文案。

### 9.2 已知不足与未来拓展
1. **多视点三维实时旋转**：  
   当前原型家具画面基于高性能正交与轴测 Canvas 2D 参数化绘制，虽然保证了轻量、离线与极快渲染速度，但若未来集成 WebGL / WebGPU 实时 3D 构件着色器，可实现围绕家具 360° 自由旋转并实施局部框选。
2. **框选区域模型语义精细度**：  
   当前原型在框选扶手、座面或椅腿后，依赖参数化变量模拟局部的收窄与材质重置；未来对接云端高级 Inpainting 模型时，可在框选选区内实施微网格局部重采样并保留边缘几何连续性。
3. **多人协作协同图纸**：  
   当前版本聚焦于单人先锋工作室，未来可在无限画布上拓展多人光标、实时批注框与分支版本合并功能。

## 1. 设计理念与核心主张

### 1.1 一句话核心主旨
> **“说一句话，把一件家具做活、改顺、做成作品。”**

### 1.2 为什么它是年轻化、超前化的？
1. **摒弃宣传腔与陈词滥调**：  
   去掉了宏大浮夸的口号与传统中式软件常见的复古图腾堆砌。界面直截了当——输入需求、即时推演、在画布上直接框选修改。用极简自信的口吻和干净直接的布局让工具自己说话。
2. **数码物态化的先锋工坊质感**：  
   中式古典家具的精髓在于骨相架构、受力榫卯、月牙弧线与虚实开光。通过 **4×4 Bayer 抖动矩阵 (点阵)** 与 **字符密度着色器**，家具被解构为网格与扫描切片，在屏幕上呈现出由计算生长的锋利秩序，彻底告别老气厚重。
3. **以画布为绝对主角的工作台**：  
   坚决不做后台管理系统或密集仪表盘。两侧面板高度收敛，删去一切无意义的修饰标签，将 80% 以上的视觉中心留给图纸画布。默认从空态出发，让每一次创作都成为从零开始的清晰体验。

## 3. 关键业务流程详述

### 3.1 首次进入 → 从空态到第一次生成
1. **主页试玩**：用户在 `index.html` 首屏直接点击器物切换（如圈椅、条案），拖动滑块体验点阵切片与纵向遮罩，或拖动拉幕滑块对比标准款与收窄款的区别。
2. **进入工作台**：点击「进入工作台」或「带入工作台」，进入 `studio.html`。
3. **严格默认空态**：工作台打开时绝非虚假的“成功”状态，而是呈现纯净优雅的空态：
   - 画布中央显示微光十字与文字提示：“输入描述，点击生成方案 或从左侧选择预设起点”；
   - 右侧评审区显示：“生成后在此查看六维打分与修改建议”；
   - 版本区显示：“暂无版本”；
   - 过程栏处于“空闲 / 准备就绪”。
4. **触发生成**：在左侧输入“宋韵极简圈椅，五接月牙扶手，纤薄轻悬，深褐黑胡桃”（或点击预设胶囊），点击「✦ 生成方案」。
5. **四阶段透明推演**：
   - 右侧进度条平稳推进：1. 理解需求与受力分析 → 2. 骨相起稿 → 3. 材质与光影 → 4. 视觉评审打分；
   - 伴随动态计时（如 `1.0秒`，`2.8秒`），右上角提供终止按钮；
   - 阶段完成，状态切为成功，画布中央空态提示消失，高品质渲染出 **V1 初稿方案**。

### 3.2 专家模型六维评审
- 任务完成后，右侧雷达条呈现文化准确性 (88)、结构合理性 (85)、材料工艺 (83)、设计创新 (82)、场景适配 (84)、算法表现 (85) 六项量化得分，综合评分 84 (达标)；
- 专家建议指出：“月牙扶手弧度圆融清雅，但前鹅脖立柱与坐盘交界处可更纤薄收束，提升轻悬感”；
- 包含「采纳建议并生成下一版」操作。

### 3.3 画布框选局部修改 (Inpainting)
1. 点击画布浮动工具条上的「⛶ 框选」；
2. 鼠标在圈椅扶手区域拖拽出一个高亮选框；
3. 选框旁弹出身位自适应的气泡框，提示“区域：扶手与搭脑构件”，输入框默认给出：“扶手减薄收窄，端头更轻”；
4. 点击「生成新版本」，系统锁定其余所有部件（椅腿、椅盘、券口牙子），只针对扶手进行收薄重算，生成 **V2 · 扶手收窄改版 (评分: 91)**；
5. 版本树自动加入 V2，画布更新为收窄后的更轻灵造型。

### 3.4 双版本滑动拉幕对比
1. 点击工具栏的「⇔ 对比」；
2. 画布中央立刻激活窗帘拉幕层，左半区为 V1 初版，右半区为 V2 扶手改版；
3. 拖拽中央青色圆手柄左右滑动，两版在鹅脖交接、扶手厚度上的毫厘改动在同一视口下清晰可辨。

### 3.5 一页导出展卡
1. 点击顶部「⤓ 导出展卡」；
2. 弹出标准化设计展卡：主图（支持点阵模式）、点阵矩阵参数 (4×4)、器物、木作、软包、尺寸规格、六维评分与版本编号；
3. 点击「下载展卡」，一键保存为高分辨率 PNG 文件。

## 4. 核心界面布局与交互说明

### 4.1 官网应用主页 (index.html)
- **口语化主标题**：“说一句话，把一件家具做活、改顺、做成作品。” 删除了所有空洞的眉标、副标题和长篇大论。
- **构形试玩操场**：器物、风格、效果、像素大小与纵向遮罩滑块，全部采用纯正中文标签，零英文括注。
- **四项核心能力**：极简 4 格卡片，文案简明，突出“分阶段推演”、“框选改一处”、“版本对比”与“一页导出”。
- **两版滑动演示**：直接让初访者拖拽滑块体验对比手感。

### 4.2 工作台系统 (studio.html)
- **去除仪表盘密集小标签**：
  彻底删去了原先卡片右上角的「中文自动增强」「锁定保留」「2 轮自修」「六维雷达」「就绪」等冗余装饰标签；
  合并了次要面板，将风格、比例与推演轮数集成在紧凑的控制行内。
- **彻底的空态心智**：
  默认不预填虚假作品，画布保持大面积深黑工坊底色，引导用户第一次点击生成。
- **去中英文混杂**：
  全站排查删除了 `(Pixel Size)`, `(Scanline)`, `Structura v2.6`, `38 tokens`, `(Rounds)`, `(1080p)`, `(Quant=4)` 等括号标注与版本号。

### 4.3 移动端 390px 深度适配（针对上一轮评审彻底修复）
1. **顶栏品牌不被挤压**：
   - 品牌名固定为短小有力的「木生」，隐藏多余长项目输入框；
   - 导出按钮紧凑化为图标按钮，桌面操作自动收纳；
   - 经实测在 390px 视口下横向占用仅 390px，零文字换行、零溢出（ScrollWidth: 390）。
2. **画布工具栏绝不折行**：
   - 手机端自动将按钮折叠为纯图标模式（`✋` `⛶` `⇔` `⚙`）；
   - 工具栏总宽度收敛在 160px 左右，居中浮动，按钮高度 34px，完全消除之前文字换成两行的尴尬现象。
3. **底部轻量五项 Tab 与抽屉吸底按钮**：
   - 底部固定高度 56px，包含 `[画布] [输入] [评审] [版本] [导出]`；
   - 点击「输入」抽屉滑出时，`✦ 生成方案` 按钮采用 `position: sticky; bottom: 0;` 吸底常驻，无论如何滑动都能一键拇指触达触发生成。

## 5. 视觉系统与 Token 嵌套体系

### 5.1 递进式圆角 Token 体系 (r = R - p)
严格满足内外共圆心几何准则，且间距与圆角严格落在 4px 网格上：

| 层级 | Token 名称 | 尺寸 | 使用场景 | 几何推导 |
| :--- | :--- | :--- | :--- | :--- |
| **层级 1** | `--radius-window` | `32px` | 导出展卡模态、全屏视窗 | 外层最高容器 ($R = 32px$) |
| **层级 2** | `--radius-card` | `24px` | 操场卡片、状态弹窗、移动端抽屉底托 | $R = 24px$，内边距 $p = 12px$ |
| **层级 3** | `--radius-panel` | `16px` | 操场控制面板、画布悬浮工具条外壳 | $r = 32 - 16 = 16px$ 或 $r = 24 - 8 = 16px$ |
| **层级 4** | `--radius-sub` | `12px` | 工作台侧栏卡片、框选气泡浮层 | $r = 24 - 12 = 12px$ |
| **层级 5** | `--radius-control` | `8px` | 输入框、按钮、分段选择项 | $r = 16 - 8 = 8px$ 或 $r = 12 - 4 = 8px$ |
| **层级 6** | `--radius-tag` | `4px` | 状态指示点、微型标签、进度槽 | $r = 8 - 4 = 4px$ (系统最小圆角) |
| **全圆** | `--radius-pill` | `9999px` | 按钮微胶囊、对比滑块手柄 | 保持全圆 |

### 5.2 连续曲率超椭圆
```css
@supports (corner-shape: superellipse(1.25)) {
  :where(*) {
    corner-shape: superellipse(1.25);
  }
}
:where(.pill, .round) {
  corner-shape: round;
}
```

### 5.3 色彩与对比度
- 画布深黑：`#090A0D`（极黑背景，烘托器物形体）
- 表层暗调：`#15181E` / 浮层 `#1C212A`
- 极光数码青：`#00F5D4`（用于高光选中、滑块、评分重点）
- 框选金：`#F59E0B`（用于局部拉框提示）
- 满足 WCAG AA 高对比度标准。

## 6. 两条指定方案落地细节

### 6.1 递进式圆角 (Nested Radius)
- 卡片（12px）→ 内边距（8px）→ 控件输入框（8px）→ 内边距（4px）→ 小标签（4px）；
- 悬浮在画布上的 CAD 工具栏：外壳圆角 12px，内边距 4px，内部按钮 8px。完全消除了内尖外圆或尖角顶圆角的不协调。

### 6.2 点阵 (Bayer 4×4) 与字符 (ASCII) 参数化着色器
- **点阵模式**：
  采用经典 4×4 Bayer 阈值矩阵进行亮度离散化，支持 2px 到 10px 像素块调节与 4 阶量化，叠加 88% 纵向扫描遮罩，在电脑与手机上均能呈现锋利的数码切片质感。
- **字符模式**：
  将画面切分为等宽字符网格，依据亮度映射字符密度，叠加 90% 扫描遮罩。
- **纯代码离线运行**：全部由 `furniture-engine.js` 驱动，不消耗网络，不调用外部模型。

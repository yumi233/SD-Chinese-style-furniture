# 同桌 · 木生 UI / UX 方案（claude）

## 理念

**木生不是一个按钮，而是坐在你对面的另一位设计师。** 工作台是一张无限延伸的桌面，你和木生各有一个光标：你写一句话、框一处，木生的蓝色光标就过来起稿、上材质、评审。年轻用户熟悉 Figma 式的多人画布和与 AI 的对话，「同桌」把两者合成一种协作感，而不是「填表 → 等待 → 拿图」。

为什么超前：版本不是列表，而是在桌面上长出来的一棵树；生成不是转圈，而是一件家具从字符被拼成像素、再拼成木头；修改不是重写提示词，而是在图上框一下、说一句。

## 信息架构

```
主页 index.html ──「画给我看」在主页内直接试玩
   └─ 打开工作台 → studio.html
        ├─ 桌面（无限画布）：版本卡片 + 版本树连线 + 木生光标
        ├─ 底部输入栏：描述 / 对选中版本说一句；单次 ↔ 迭代；风格
        ├─ 右侧评审面板（手机为底部抽屉）：总分、六圈年轮、建议、材质、锁定、英文提示词
        ├─ 叠层：比较（拖动 / 叠看 / 并排）、导出设计页
        ├─ 左上：作品抽屉（历史）、作品名、设计记忆标签
        └─ 右上：协作者、连接状态、状态演示、导出
```

## 关键流程

1. **首次进入**：空桌面中央是一把慢慢转动的字符椅子和一句「写一句话，木生就开始画」，下面三个种子描述，点一下就开始。
2. **第一次生成**：卡片出现在桌面上，木生光标移过来，依次经过四个真实阶段：
   - 理解需求：描述被拆成几个标签，逐个弹出（椅 · 黑胡桃 · 明式 · 轻）；
   - 起稿：字符一格一格聚拢成家具（ASCII）；
   - 出图：像素块从 10px 逐级收细到 3px（Dither），最后去模糊成为实木；
   - 评审：分数环出现在卡片右上角，右侧面板展开六圈年轮。
3. **评审 → 修改**：点一条建议，相应部位在图上亮蓝，同时弹出修改气泡，修改语已预填。
4. **框选改一处**：卡片上点「改一处」，在图上拖框，木生识别框里的部件（扶手 / 靠背 / 腿…），气泡里说一句「再薄一点」。新版本从原卡片长出，连线流动，生成完成后改动部位短暂高亮。
5. **比较**：「对比」→ 点另一张卡片。三种方式：拖动分界线、半透明叠看（拖动即调透明度）、左右并排。
6. **导出**：一页图 + 作品名 + 版本 + 材质风格 + 六维分数，下载 PNG。
7. **回到历史作品**：左上「作品」抽屉，缩略图 + 版本数，点击后整棵版本树恢复到桌面。

迭代模式：未达 85 分时木生自动选最弱的一条建议修正，新卡片自动长出，最多 3 轮，最后提示达标或已到上限。

## 核心界面

- **桌面**：点阵纸底；拖拽平移、滚轮平移、⌘/Ctrl + 滚轮或双指缩放；左下缩放控件（−/百分比/+，点百分比回到选中卡片）。
- **版本卡片**：版本号、标题、分数环；画面；底部四个动作（改一处 / 再来一版 / 对比 / 下载）。选中描黑框，选择对比目标时描蓝框。
- **输入栏**：一行自增高文本框。选中已完成版本时，按钮变为「修改 v2」，占位语变为「对 v2 说：扶手再薄一点」，同一个入口既能新建也能修改。生成中按钮变红色「停止」。
- **评审面板**：大号总分；六圈年轮（最外圈蓝色为文化准确性）配六行分数；建议可点；材质圆点直接换材质（生成新版本）；锁定材质 / 靠背 / 比例后显示在左上「设计记忆」里，后续每一版都保留。
- **移动端（390）**：顶部只留标志、作品与状态；顶部下方是横向版本条；输入栏贴底；评审面板变成底部抽屉，露出 64px 把手。

| 木生（协作者）| 电光蓝 #3D5AFE，只用于木生光标、木生的动作和被改动的部位 |

### 圆角 token 与嵌套（帖子 004）

`--r-xs 4 · sm 8 · md 12 · lg 16 · xl 20 · 2xl 24 · 3xl 28 · 4xl 32 · full`

| 外层 | 间距 | 内层 |
| --- | --- | --- |
| 浮动栏 20 | 4 | 按钮 / 标题输入 16 |
| 输入栏 28 | 8 | 文本框、生成按钮 20；分段控件 20 − 4 = 16 |
| 版本卡片 24 | 8 | 画面、底部按钮 16 |
| 评审面板 28 | 12 | 区块 16 |
| 缩放 16 | 4 | 按钮 12 |
| 修改气泡 20 | 4 | 部件标签、输入、按钮 16 |
| 比较 / 导出 32 | 16 | 画面 16 |
| 主页效果实验室 32 | 12 | 画面、面板 20；面板 20 − 8 = 12；分段 12 − 4 = 8 |

所有圆角都支持 `corner-shape: superellipse(1.25)` 渐进增强；胶囊、头像、圆点、滑块保持 `round`。

### 字符 / 像素 / 切片（帖子 003）

同一个参数化光线投射引擎 `furniture.js` 输出四种画法：ASCII、4×4 Bayer Dither、横向切片、实木。它们不是滤镜，而是家具本身的**成形阶段**：

- 工作台：起稿 = ASCII 聚拢；出图 = Dither 逐级收细；完成 = 实木。
- 主页「一格一格」：三种画法切换，可调颗粒（字号 / 像素块 / 切片步长）、解体（爆炸距离）、遮罩（纵向三段：顶 90%、42% 处 20%、底 70%）。
- 被改动的部位在所有画法里都用蓝色标出。

## 八类状态

| 状态 | 表现 |
| --- | --- |
| 空态 | 转动的字符椅子 + 一句话 + 三个种子 |
| 生成中 | 卡片内阶段标签（带闪点）、木生光标随阶段移动、连线流动、面板显示四阶段进度 |
| 部分结果 | 迭代模式下，已完成的轮次保留分数，下一轮卡片正在生成 |
| 成功 | 分数环、面板展开、改动部位高亮 1.6 秒 |
| 失败 | 卡片画面斜纹 +「出图失败 · 这次没有扣次数」+ 重试 |
| 已停止 | 画面冻结在当前阶段，标签「已停止 · 出图」，面板提供「继续生成」 |
| 断线 | 右上红色「连接断开，正在重连」，动画暂停；恢复后提示「已重新连接，继续生成」 |
| 刷新恢复 | 提示「已恢复上次的任务」，从中断阶段继续 |

右上「状态」菜单可以直接切换这八类状态，也可以用 `studio.html?state=失败` 打开。

## 自检

已验证：

- `node --check` 通过 furniture.js、studio.js、home.js。
- 用无头 Chromium 实际点击：种子描述 → 生成 → 卡片出现并得 85 分；成功场景加载两版并能选中；无控制台错误、无横向溢出。
- 主页桌面 1440 与手机 390 截图：首屏椅子完整、选词与按钮在首屏内。
- 修复：画布接管指针导致空态种子点不动；`hidden` 被 `display` 覆盖导致断线提示常显。

第二轮自评后修改：

- 迭代模式分数不涨、建议与修正自相矛盾 → 每条建议带上对应的修改语，后一轮基于评审得到提升（实测 84 → 88，达标停止）。
- 生成中评审面板是一大块空白 → 面板高度随内容。
- 首页椅子超出画布、空阶段标签常显、手机评分卡压住椅子、木纹条带过重 → 已修。
- 合成指针事件下 `setPointerCapture` 抛错 → 加保护。用 CDP 实测：框选 → 识别部件 → 说一句 → v3 生成并评分；比较打开；主页拖框修改 v1 → v2。

不足：

- 家具由盒体拼成，造型偏方，还不是真正的圈椅曲线；真实模型返回的是位图，正式版需要把「字符 / 像素 → 实图」改为以真实图片为源做显影。
- 部件识别依赖参数化模型，接入真实图片后只能作为提示，不能保证精确。
- 断线目前只是演示，没有接任务轮询；手机 Safari 与低端设备性能尚未真机验证。

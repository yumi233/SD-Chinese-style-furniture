# 木生 · 形场

> 让每一稿，都在同一张图纸上继续生长。

代号：astra。第二轮，根据项目总设计的首版评审修改。当前实现以本文件和 `public/proposals/astra/` 为准；第一轮证据保留在 `evidence/`，本轮证据独立放入 `evidence/revision-2/`。

## 本轮改动

- 保留首页蓝色点阵圈椅、颗粒滑杆、效果调节与底部输入。去掉图上的编号眉题、说明标签、辅助标语及正文重复解释，点阵 / 字符使用中文控件名称。
- 撤掉工作台左右常驻栏。整屏点阵图纸为主角，底部浮动输入栏只保留需求、设置、灵感与生成。风格、构图、英文提示词、设计记忆全部移入按需打开的设置弹窗。
- 空态只保留「从一句话开始。」这一句；隐藏导出、画布工具、评审与版本，不出现保存标语、快捷键说明或假评分。保存状态仍可被辅助技术读取，失败时显示明确错误。
- 评审和版本是互斥的临时面板，可随时收起。桌面评审浮在右侧，画面在剩余可见区域居中；版本浮在底部。手机两者在画布下方自然展开，没有压缩的三栏，也不覆盖画布或固定底部按钮。
- 四阶段与视觉转换同步：理解需求用蓝色 ASCII 轮廓；起稿用粗 Dither；出图用细 Dither；评审用更细点阵；完成后显示原形。沿用首页的采样器和深色工具条，不增加无意义的粒子动画。

## 理念、受众与取舍

面向学生、年轻家具设计师和小型工作室。以持续设计一件作品为目标，而非填写一整页表单。年轻感来自清晰的直接操作、钴蓝色与大面积图纸；超前感来自字符 / 像素组成的家具逐渐变为可迭代的作品。页面不使用复古装饰、家具照片、虚构用量或后台指标卡。

唯一主角是家具，主动作是生成 / 修改下一版。删除解释性小字、装饰英文、面板角标和无对象时的面板；保留输入标签、可操作名称、任务状态、错误与必要数字。六维名称和修改建议直接影响决策，因此保留；泛泛的「一起推敲」「可以留下的一版」不再占据界面。

未委派模型或子代理，未调用付费生成、联网取图或安装依赖。沿用已读取 oil-ui 的层级与实际画面验收方法，设计判断和实现均由主模型完成，未声称独立评审。

## 信息架构与关键流程

```text
首页 index.html
 ├─ 点阵 / 字符 / 原形 + 参数实验
 ├─ 输入需求 → 工作台新草稿
 └─ 作品集 → 恢复作品
工作台 studio.html：一张连续画布
 ├─ 浮动输入 → 生成 → 字符 / 点阵四阶段 → 结果
 ├─ 设置弹窗 → 风格 / 构图 / 提示词 / 设计记忆
 ├─ 画布工具 → 平移 / 缩放 / 框选 / 批注
 ├─ 评审 → 六维分数 / 采用建议 / 自由修改 → 新版本
 ├─ 版本 → 任意版本 / 比较 → 选定一版继续
 ├─ 导出 → 作品页 / 主图 PNG
 └─ 作品集 / 登录与注册
```

首次进入：在主页尝试纹理，用底部输入把需求带进工作台。空态没有结果或评分；可以直接生成，也可在设置中补充条件。生成不要求原型登录，显示明确阶段，允许停止。

第一次完成：家具与六维评审出现。用户可直接修改、采纳建议、在画布框选或回看版本。框选先收起评审和版本，修改输入取代原需求栏；产生新版本后保留原稿与父版本关系。比较器可选择任意两版，显示图、修改词和分差，选择右侧版本继续。导出先预览再下载。

回到历史：作品集按更新时间排列会话，恢复完整需求、参数、版本、选中项与批注；删除需要确认，取消不删除。原型使用独立 localStorage 命名空间，与原应用数据分离。

## 核心界面与交互

### 首页

保留「让想法，长出下一版。」与可玩圈椅。素材全部来自程序化 Canvas，未使用仓库照片。颗粒、字号、取样强度、纹理尺度、取样区域与纵向遮罩均可操作。首屏以作品、工具条、输入为主，不再放图旁标签与介绍性小字。

### 工作台与设置

桌面顶部只有品牌、作品名和作品操作；画布横跨整个工作区。浮动输入栏最大 760px，底部距工作区 24px。关闭所有临时面板后即可回到完整画布，不留下空白侧栏。

设置用原生 dialog，支持 Escape、焦点限制与返回触发控件。风格四选一；构图包含 16:9 / 4:3、720p / 1080p、精细度、氛围与约束；自动迭代默认目标 85、上限 2 轮，最多 3 轮。英文提示词可编辑并保存快照。记忆可锁定白蜡木与当前比例。快捷键与状态演练放入设置的次要操作，不出现在空态。

### 生成过程

阶段真实对应原型内部任务进程，不用随机百分比。四个阶段都可观察：字符轮廓 → 粗点阵 → 出图的细点阵 → 评审的精细点阵 → 原形。预览使用当前任务家具类别，茶桌不会在等待时变成圈椅。模拟设计材质不因预览染蓝而改变。

出图阶段创建唯一待评审版本；评审阶段再补分数。任务保存阶段与 candidate ID，刷新继续原候选。停止保留已有结果，重试不会重复新增。自动迭代达到目标或用完轮次即止。错误保留次数说明，原型未扣次数；生产环境必须读取后端真实计费结果。

### 画布与局部修改

鼠标拖动 / 手机单指平移，滚轮或按钮缩放。键盘聚焦画布后用方向键平移、＋ / − 缩放、0 复位。框选提供初始矩形，也能拖出自己的区域；提交保存选区、缩放、平移及修改词。批注保存到版本。

本轮避免选区输入与原需求同时出现，避免评审浮层挡住选区。原型的选区是交互演示，实际图像仅做厚度 / 宽度等程序化参数调整，不宣称模型像素级局部重绘。

### 评审、版本与比较

评审浮层只显示六维分数、一条可执行建议和修改输入。总分 52px，六维条形辅助，不盖在作品上。高分后的建议是打样验证接合强度与承重，评分不替代工程验证。「更多操作」收纳同参数重跑与回填描述。

版本底片显示图、编号、评分、最佳标记和来源；任意版本都能继续分支。比较可选择任意两版，同版比较禁止继续；待评审版本不制造虚假分差。桌面并排，手机上下排列，通过弹窗自身滚动查看两张图和底部继续按钮。

### 账号、历史与导出

账号展示登录 / 注册 / 表单校验与跳过，不发送或保存凭据。真实账号与个人资料同步未接入，普通用户不展示管理员设置。历史恢复不复制新会话。

作品页为 1200 × 1500 PNG，包含主图、材质、说明、版本与六维评分；主图按配置输出 16:9 / 4:3、720 / 1080 的 PNG。空态不显示导出，生成时已有版本的导出呈明确灰色禁用状态。

### 390px 移动端

顶部 64px，画布先行，下方按状态出现输入、进度、选区编辑或评审 / 版本。输入不是固定遮挡式底栏，短屏允许自然滚动；390 × 640 时画布降为 332px，保留完整操作。评审和版本互斥展开，原需求暂时收起，点击「画布」恢复。选区输入纵排，按钮整行宽，不出现文字挤成竖排。

比较与设置弹窗限制在视口内，内部可滚动；设置「完成」贴近弹窗底部，键盘使用原生 dialog 焦点行为。没有强制拖拽才可完成的步骤。

## 视觉系统

颜色：背景 `#f3f4f6`、浮层 `#ffffff`、正文 `#20242c`、次级必要信息 `#626873`、分隔 `#d9dde5`、主色 `#244be8`、选中底 `#e9edff`、深色操作条 `#202b44`。错误 `#a63235`、警告 `#805600`、成功 `#256049`。保留第一轮已核验的核心文字配色对比度。

字体使用系统栈 `-apple-system / BlinkMacSystemFont / PingFang SC / Microsoft YaHei / sans-serif`，不下载字体。主页标题最大 84px，手机 52px；空态桌面 36px、手机 28px；输入 15–16px；标签 13–14px；必要版本数字 12px。

间距 token：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48px。圆角嵌套关系：

```text
桌面弹窗 R32，p16 → 内容 R16，p8 → 控件 R8，p4 → 标签 R4
手机弹窗 R24，p12 → 内容 R12，p4 → 控件 R8
浮动输入 R24，p8 → 操作按钮 R16
评审 / 选区浮层 R24，p16 → 输入及按钮 R8
版本卡 R16，p8 → 缩略图 R8
深色工具条 R16，p8 → 按钮 R8
分段控件 R8，p4 → 选项 R4
头像与编号标记 → 全圆
```

相邻嵌套边缘采用 `r = R − p`，最小 4px。无边框画布不强行卡片化。连续曲率使用 `@supports (corner-shape: superellipse(1.25))` 渐进增强，圆形覆盖为 `round`，不支持时正常圆角回退。

## 指定 ASCII / Dither 方案

共用 `furniture.js`：先在离屏 Canvas 生成家具，再网格采样亮度。ASCII 用 `. , : ; + = * # % @` 从疏到密映射，可调字号、格距、对比及暗部 / 亮部。Dither 用 4×4 Bayer 阈值量化为 2–6 级，块大小、纹理尺度、强度独立可调。默认纵向遮罩 ASCII 90、Dither 88，保留轮廓可见性。

首页是参数实验；工作台生成时使用同一渲染器，按阶段调整字符、颗粒与细度；结果可再切换点阵 / 字符检查。不会用随机噪点遮罩冒充家具数字化，不引入照片、实时三维模型或外部素材。

动效：按钮反馈 140ms、浮层出现 240ms / 8px、进度条 240ms；生成画面在阶段转换时重算，连续移动不用于伪装进度。`prefers-reduced-motion` 关闭动画、过渡与平滑滚动，仍保留表达任务状态的静态阶段图。

## 八类状态

| 状态 | 呈现与处理 |
| --- | --- |
| 空态 | 一句提示 + 输入；导出、工具、评审、版本隐藏 |
| 生成中 | 蓝色字符 / 点阵与四阶段；允许停止，输入暂时收起 |
| 部分结果 | 细点阵主图已出现，待评审版本已保存，继续同一个候选 |
| 成功 | 原形、评分、修改与版本操作；只展开评审，不出现两个侧栏 |
| 失败 | 明确服务错误、次数说明与重试；需求和旧版不丢失 |
| 已停止 | 保留已有图和版本，停止自动后续轮次，可继续同一任务 |
| 断线 | 保存任务与阶段，恢复连接后继续原任务 |
| 刷新恢复 | 从已保存的阶段 / candidate 接续，不新增重复版本 |

设置里的状态演练会创建独立作品，原作品保留。存储失败用可见错误提示，不显示虚假保存成功，仍可导出。

### 尚存限制

- 家具仍为椅 / 桌 / 柜三种程序化结构，评审是模拟分数；局部编辑保存选区但只改变构件参数。风格、氛围、精细度和约束保存为快照，不接真实模型；英文增强是模板。

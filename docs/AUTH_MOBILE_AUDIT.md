# 登录与移动端整改审查

版本：`20261010-auth-mobile-r4`。沿用 PR #1 的纸、墨、朱砂制图台；本次调整排版和状态行为，没有重做品牌视觉。采用 oil-ui 与 Apple Design 的移动端重组、可读状态、明确关闭入口和减少动效原则；一次独立截图评审，无虚构视觉评分。

## 发现与修复

| 问题 | 修复及验证 |
| --- | --- |
| 较早的匿名会话响应覆盖刚完成的登录，重复提交无锁 | AuthCoordinator 串行写操作并忽略过时查询；浏览器延迟响应、重复表单提交验证只发一次登录请求 |
| 登录失败统一提示“请先登录”，数据读取故障也误报密码错误 | 分开凭据错误、限流、网络超时、Cookie 未保存和服务故障；测试损坏存储返回 500，保留文件、拒绝授权且不消耗密码失败额度 |
| 退出残留上一账号结果、历史、表单，旧请求可能重新填入 | 清理私有工作区并按账号和请求版本拒绝过时响应；延迟历史响应在退出后释放，界面仍为空 |
| 手机输入栏悬浮覆盖结果，工具栏使用固定顶栏偏移 | 输入栏进入正常文档流，ResizeObserver 按真实顶栏高度更新工具栏；320/390/768/1280 宽度无页面横向溢出，画布不覆盖输入栏 |
| 参数面板缺少明确关闭入口，弹窗不适应小屏和键盘视口 | 增加关闭按钮和遮罩；账号、设置、历史滚动布局使用 visualViewport，窄屏控件有可触达高度；Esc 关闭及焦点返回验证 |
| 手机多轮结果纵向堆叠，触摸下操作依赖悬停 | 横向胶片条、吸附滚动、常显操作；设置导航横向滚动且文字不拆行；极窄屏状态单独一行，避免被导航挤压 |
| 历史恢复叠加旧图、引擎与参数不完整，三轮结果显示第二轮评分 | 恢复替换当前画布并还原引擎、负面词、Seed 与迭代参数；最后轮次从实际最后一轮读取。恢复两次仍为三张图，最后轮评分 90；生成期间禁止恢复覆盖当前任务 |
| 生成中的历史删除后可被后续轮次重新保存 | 活跃任务记录删除返回 409，完成后可删除；用户权限检查先执行；页面显示明确错误 |
| 非 CLI 旧生成路由绕过并发和每小时限制 | 各引擎与旧路由统一使用任务创建、所有权和幂等校验；保留非 CLI 同步 200/CLI 202 契约，回归覆盖限流和失败不重复生成 |

模型选择从不可见的键盘控件移入参数面板；默认仍为 Codex CLI。普通生成也可打开「约束」面板查看解析内容。

## 验证证据

- `make check`：71 项测试全部通过，包括并发认证、账号隔离、CLI 输出与凭据保护、任务恢复、旧接口限制、存储故障和活跃历史删除；新增前端模块语法校验。
- 开发、源码构建、生产 Compose 的全部 Profiles 均通过 `config --quiet`。配置检查不等于已经上线。
- 隔离容器仅绑定本机 `3101`，用户和图片保存在临时 tmpfs，无生产凭据或模型调用。普通生成及三轮智能体使用模拟图像网关；真实认证、任务和历史模块负责持久化与权限。
- Playwright 从实际入口验证注册、密码错误、登录、退出、刷新保持会话、重复提交、慢查询忽略、普通生成、三轮评分、历史筛选/恢复、放大切换和授权 PNG 读取。修复后的认证竞态验收无页面脚本异常。
- 日夜主题、大字号、繁体、减少动态效果、200% CSS 放大、窄屏首页和账号小视口另行复核。CSS 放大与视口模拟不能代替实体设备测试。
- 截图在任务工作目录 `output/playwright/`，不发布为生产资产：`mobile-restored-final.png`、`mobile-history-fixed.png`、`settings-320-final.png`、`lightbox-320.png`、`account-small-viewport.png`。独立截图评审指出结果区过长与设置导航拆字，已修复；删除了重复错误弹出提示，保留原界面必要文案。

## 生产与限制

生产与本地账号独立；本轮审查时生产没有已注册账号，因此本地账号不能直接登录正式网站。没有导入预览账号、自动授予管理员、修改密码或引入登录绕过。

生产沿用 `furniture-ai` Stack、`furniture-ai-data`、`personal-hub-edge` 和原 CLI 登录缓存；发布以固定镜像和公网 `X-Musheng-Revision` 核验。升级前备份，回滚切回 `20261010-codex-r3`，不删除数据卷。

手机验证为 Chromium 模拟，不宣称实体 iPhone Safari 验收。账号服务仍是单实例 JSON 存储，没有邮件验证或密码重置；本次未新增外部账户服务。模型可用性受额度与网络影响，本次模拟生图不证明外部模型在线；上一版真实模型结果见 [生产文档](CODEX_PRODUCTION.md)。
